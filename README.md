# 🔎 Search Algorithm Visualizer (Python + Pygame)
This project visually demonstrates how different uninformed search algorithms explore a grid to find a path between a start and goal node.
It allows users to interactively select and run different search algorithms while observing:

* Frontier expansion
* Explored nodes
* Final path found
* Step-by-step visualization

## 🚀 Implemented Algorithms
* Breadth-First Search (BFS)
* Depth-First Search (DFS)
* Uniform Cost Search (UCS)
* Depth-Limited Search (DLS)
* Iterative Deepening DFS (IDDFS)
* Bidirectional Search

## 🎮 Features
* Interactive grid visualization
* Random wall generation
* Algorithm selection buttons
* Step animation with adjustable speed
* Reset functionality
* Visual legend for node states

## 🛠️ Tech Stack
* Python
* Pygame

## ▶️ How to Run

```bash
pip install pygame
python main.py
```

## 🎓 Purpose
This project was built for understanding and visually comparing search algorithms in Artificial Intelligence and Data Structures.
